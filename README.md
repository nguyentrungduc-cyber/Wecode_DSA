# Wecode_DSA

Bài tập thực hành môn Cấu trúc dữ liệu & Giải thuật (cô Vân), làm trên nền tảng Wecode.

## Cấu trúc

Mỗi file `wecodeX_Y.cpp` là 1 bài nộp trên Wecode, đánh số theo chương (X) và thứ tự bài (Y). File `graph1.cpp` đến `graph4.cpp` là các bài riêng về thuật toán đồ thị (BFS/DFS, dùng queue).

Một số file có comment `###Begin banned keyword...` — đây là ràng buộc do Wecode chèn vào (cấm dùng 1 số từ khóa nhất định khi chấm bài), không phải lỗi.

## Ngôn ngữ

C++ (STL: vector, queue...).
